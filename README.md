## ⚙️ Setup & Installation

### 1. Environment Configuration
Clone the repository and set up your environment variables:
```bash
cp .env.example .env
```

### 2. Run with Docker Compose
The easiest way to spin up the entire stack (App, DB, Redis) is using Docker Compose:
```bash
docker-compose up --build
```

### 3. Manual Installation
If running locally without Docker, ensure you have PostgreSQL and Redis active, then:
```bash
npm install
npm start
```
